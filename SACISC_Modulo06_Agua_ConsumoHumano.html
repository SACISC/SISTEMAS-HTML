⚙ Conexión a la base de datos (Supabase)

Mientras no se configure, el sistema sigue guardando todo localmente en este navegador (como hasta ahora). Al conectar Supabase, la captura, comodatos, reportes y la matriz de suministro se leen y guardan directo en la base de datos del proyecto.

⬆ Subir mis datos de este navegador a Supabase

Conectar a Supabase no mueve por sí solo lo que ya tenías capturado en este navegador antes de conectar — Supabase empieza vacío (o con lo que ya tenga otra persona) hasta que subas tus datos locales con este botón. Úsalo una sola vez por navegador, justo después de conectar, si en esa computadora ya habías capturado algo.
La URL y la llave se guardan solo en este navegador (localStorage), nunca se envían a ningún otro lado. Ejecuta primero 01_schema_agua.sql y 02_seed_agua.sql en el Editor SQL de tu proyecto de Supabase antes de conectar.
